# Harness-Optimizer

Token-optimized MCP tool suite for OpenCode. One command installs a local
Python MCP server, three plugins, four custom commands, and global rules.

## Quick Start
    npx harness-optimizer

## Commands
    npx harness-optimizer --doctor      # health check
    npx harness-optimizer --uninstall   # clean removal
    npx harness-optimizer --force       # reset to defaults
