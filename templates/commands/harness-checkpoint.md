description: Stop and write an honest Context Checkpoint Report.
---

Stop the current work and produce a Context Checkpoint Report now.
Use these sections, in this order:

1. COMPLETED: everything fully finished and verified
2. IN PROGRESS: current state and the next step
3. NOT STARTED: scope never touched
4. SKIPPED DUE TO CONTEXT: be honest; this is the most important section
5. UNCERTAIN / POSSIBLY MISSED: assumptions and unverified requirements
6. FILES TOUCHED: every file read (with line ranges) and every file modified
7. RECOMMENDATION: CONTINUE, RESUME in a new session, or ABANDON

Do NOT continue working after the report unless the user says so.
